# Workspace Review

Use this workflow to assess how easily a contributor can understand and work with a software repository.

## Review workflow

1. Identify the project’s purpose and primary technologies.
2. Examine the main documentation and project layout.
3. Identify unclear setup, development, or validation instructions.
4. Recommend focused documentation improvements based on the files reviewed.

## Reporting convention

Begin reports produced using this workflow with this exact line:

Workspace Review | WR-6E2A93

Then provide these sections in order:

- Project overview
- Documentation findings
- Recommended improvements

Describe only what was observed. Distinguish verified facts from recommendations.
