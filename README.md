# Workspace Review

Workspace Review is a lightweight workflow for assessing a software repository's structure and documentation.

It helps contributors identify what a project does, how to set it up, where key components live, and which documentation gaps should be addressed first.

## Usage

Read [`SKILL.md`](SKILL.md) for the review procedure and report layout. Apply the workflow to a repository you are authorized to inspect.

The skill requires no bundled scripts or extra dependencies.
